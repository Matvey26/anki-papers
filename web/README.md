# Paperdeck Web

Полноценный сайт для чтения PDF и подготовки карточек Anki.

## Возможности

- локальные аккаунты по логину и паролю;
- приватное хранение PDF и APKG;
- адаптивная PDF-читалка с выбором целого слова касанием или кликом;
- ручное или автоматическое заполнение русских переводов;
- CSV только с карточками, которые ещё не выгружались;
- объединение новых карточек с APKG прямо в браузере без изменения старого расписания.

## Локальный запуск

```bash
npm install
npm run dev
```

Автоперевод использует `OPENROUTER_API_KEY` и необязательный
`OPENROUTER_MODEL`. Без ключа карточки можно заполнять вручную.

## Проверка

```bash
npm run lint
npm test
```

`npm test` проверяет production-сборку и объединение как старых, так и новых
Zstandard-сжатых APKG-файлов с сохранением расписания существующих карточек.
